# Getting help

- **Questions and bugs:** open an issue in the repository you are using. Include the version, the host tool and its
  version (for example Claude Code or Hermes Agent), and what you expected to happen.
- **Security problems:** follow [SECURITY.md](SECURITY.md); do not open a public issue.
- **Upstream behaviour:** a problem that also happens in the original project belongs there as well. For the compaction
  engine that is [tamaratran/fast-jev-compaction](https://github.com/tamaratran/fast-jev-compaction).

This is maintained in spare time, so there is no guaranteed response time.
