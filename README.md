# .github

Organization profile and default community health files for
[deadczarvc-labs](https://github.com/deadczarvc-labs).

| File | Used for |
|---|---|
| [`profile/README.md`](profile/README.md) | The public organization page |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute, for every repository without its own file |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Community standards |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default issue forms |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Default pull request template |

A repository that ships its own file of the same type overrides the default here.
